Astra is autonomous AI penetration testing running on local infrastructure. Point it at an authorised target, and it runs the whole assessment on its own, then documents every finding with the exact command and raw output.

Open source. GPLv3 and self-hosted, every agent's methodology is plain Markdown you can read, diff and fork.
Finds AND proves. Each vulnerability ships with the exact command and raw output (exploitation is agent-asserted; the Pro remediation retest is the machine-verified step), so there is almost nothing to triage.
Runs on a local LLM + Privacy Gateway. The gateway tokenizes your real IPs, hosts and credentials locally, so the model reasons on placeholders while real values stay on your perimeter.
Everywhere you build. Run it from GitHub, GitLab, Jenkins, VS Code, JetBrains, n8n, Grafana or Splunk — the open-source edition works with the CLI-based ones.
